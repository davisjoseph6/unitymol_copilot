* UnityMol Copilot - README
:PROPERTIES:
:CUSTOM_ID: unitymol-copilot---readme
:END:
A natural language interface for UnityMol using FastAgent and Ollama.

** Overview
:PROPERTIES:
:CUSTOM_ID: overview
:END:
UnityMol Copilot is a natural language interface for UnityMol,
allowing users to control the molecular visualization application
through conversational commands. It uses the =DeepSeek-Coder-V2=
language model via =Ollama= to interpret user requests and generate
appropriate UnityMol API calls.

** Features
:PROPERTIES:
:CUSTOM_ID: features
:END:
- Natural language interface to UnityMol's API
- Support for all UnityMol API functions
- Conversational mode for direct interaction
- Context-aware interactions that remember loaded structures and
  selections
- Robust error handling and logging

** Requirements
:PROPERTIES:
:CUSTOM_ID: requirements
:END:
- Python 3.6+
- Ollama with DeepSeek-Coder-V2 model installed
- UnityMol with ZMQ server enabled
- FastAgent from =mcp_agent.core.fastagent=
- PyZMQ library

** Installation
:PROPERTIES:
:CUSTOM_ID: installation
:END:
1. Make sure you have Ollama installed and the DeepSeek-Coder-V2 model
   pulled:

   #+begin_example
   ollama pull deepseek-coder-v2:16b
   #+end_example

2. Install the required Python packages:

   #+begin_example
   pip install pyzmq
   #+end_example

3. Make sure FastAgent is installed in your environment.

4. Clone or download this repository to your local machine.

** Usage
:PROPERTIES:
:CUSTOM_ID: usage
:END:
*** Starting UnityMol with ZMQ Server
:PROPERTIES:
:CUSTOM_ID: starting-unitymol-with-zmq-server
:END:
Make sure UnityMol is running with its ZMQ server enabled. The default
port is 5555.

*** Running the Copilot
:PROPERTIES:
:CUSTOM_ID: running-the-copilot
:END:
To start the UnityMol Copilot:

#+begin_example
python main.py --host localhost --port 5555 --model deepseek-coder-v2:16b
#+end_example

You can then interact with the copilot by typing natural language
requests:

#+begin_example
You: Load PDB file 1CRN
Copilot: I'll load the PDB file 1CRN for you. Let me do that now.

I've executed the command: fetch("1CRN")

The structure has been successfully loaded. The result is "1CRN", which means the structure with ID 1CRN has been loaded into UnityMol. You can now visualize and manipulate this protein structure.

Would you like me to apply any specific visualization or representation to this structure?
#+end_example

** Architecture
:PROPERTIES:
:CUSTOM_ID: architecture
:END:
The UnityMol Copilot consists of the following components:

1. *UnityMolZMQ*: Handles communication with UnityMol through its ZMQ
   server
2. *UnityMolCopilot*: Integrates FastAgent with the ZMQ communication
   layer
3. *Main Script*: Provides a command-line interface to the UnityMol
   Copilot
4. *Configuration File*: YAML file for FastAgent configuration

** Limitations
:PROPERTIES:
:CUSTOM_ID: limitations
:END:
- The copilot requires UnityMol to be running with the ZMQ server
  enabled
- Complex requests may require multiple interactions
- The copilot's understanding is limited by the language model's
  capabilities

** Troubleshooting
:PROPERTIES:
:CUSTOM_ID: troubleshooting
:END:
If you encounter errors related to FastAgent compatibility, make sure
you're using the latest version of FastAgent. This implementation uses
the decorator-based approach with YAML configuration files as required
by the current FastAgent API.
